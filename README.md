# GlicoGuard 
  

> Sistema inteligente para monitoramento e gestão de índices glicêmicos. 

---

## 📋 Sobre o Projeto
O **GlicoGuard ** é uma solução de software desenvolvida para auxiliar no controle de dados de saúde. O projeto aplica conceitos avançados de Engenharia de Software, incluindo padrões de projeto, automação de infraestrutura e foco na experiência do usuário.

## 🚀 Tecnologias Utilizadas
O ecossistema do projeto é baseado em **Java** e utiliza as seguintes tecnologias:

*   **Linguagem:** Java 17+
*   **Gerenciamento de Dependências:** [Maven](https://maven.apache.org/) (Repositório `.m2` integrado)
*   **Serialização/JSON:** Jackson (Core, Databind, Annotations, JSR310)
*   **Logging Profissional:** Logback Classic & SLF4J
*   **Automação:** Scripts em PowerShell (`.ps1`) e Shell Script (`.sh`)
*   **CI/CD:** GitHub Actions para automação de ambiente

## 📂 Estrutura de Arquivos
A organização do repositório segue padrões de escalabilidade:

*   `/ux`: Documentação e ativos focados na experiência do usuário.
*   `/.github`: Configurações de automação e hooks de atualização (Java Upgrade).
*   `/.m2`: Cache de dependências para garantir a reprodutibilidade do build.

## 🛠️ Instalação e Execução

### Pré-requisitos
*   Java JDK 17 ou superior.
*   Maven 3.8.x instalado.
